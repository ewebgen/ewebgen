⚙️ General Interface & Defaults

Save Image while clicking "Save As"

Enabled (Lazy Load): Images are kept as remote URLs during creation. They are downloaded to the server only when the user clicks "Save As".
Disabled (Eager Load): Images are downloaded to the server immediately during website generation.

Enable Limit

If enabled, requests exceeding this limit will trigger a new agent instance (load balancing logic).

If checked, users will not be asked for their Country and Language on first login. They will be prompted during checkout or upgrade instead.

Show Live Preview During Generation

Enabled: Users see the website layout building and code streaming in real-time.
Disabled (Default): Users only see the progress percentage circle. The website is hidden and appears instantly once 100% complete.
